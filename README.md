# xinchen-use Bucket

## Usage

To add this bucket to scoop, run the following command in PowerShell:

```
scoop bucket add xinchen-use https://github.com/xinchenliu998/xinchen-use
```

then

```
scoop install xinchen-use/<app_name>
```
